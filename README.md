# Brand Exploration

Плагин для создания цельного брендборда по загруженному логотипу. Результат — одно широкое изображение примерно 1600 × 1000 px с девятью разделами, как в презентации дизайн-агентства.

Плагин содержит навык с инструкцией для модели. Изображение создаёт доступный в чате инструмент генерации. Сам пакет не содержит сервера, внешнего API, ключей, телеметрии или отдельного приложения.

## Что входит в изображение

| Раздел | Содержание |
| --- | --- |
| Logo Variations | 4 версии: исходная цветная, чёрная, белая на тёмном фоне, альтернативная цветовая |
| Typography Exploration | 6 шрифтовых пар в сетке 2 × 3, названия обоих шрифтов и примеры текста |
| Color Palette | 5–6 цветов с HEX, включая тёмный, светлый и акцентный |
| Brand Elements / Icons | 5 минималистичных плоских иконок с короткими подписями |
| Brand Imagery | Ряд из 5 изображений в стиле реальной фотографии |
| Pattern & Texture | 4 образца паттернов или фактур |
| Moodboard | 6–8 тесно кадрированных изображений без текста поверх |
| Brand in Action | 2–3 реалистичных мокапа с логотипом |
| Call to Action Examples | 4 кнопки, включая залитые и контурные |

Фон белый или почти белый. Логотип расположен слева; остальные разделы — справа и ниже. Цвет, характер типографики, фотографии и графика выводятся из визуального языка исходного знака.

## Использование

1. Установите плагин и начните новый чат с доступной генерацией изображений.
2. Выберите Brand Exploration через меню плагинов или навыков. В Codex навык можно вызвать как `$brand-exploration`; в ChatGPT — выбрать через `@`.
3. Прикрепите логотип и напишите: «Создай Brand Exploration board по этому логотипу».

Название бренда и слоган можно добавить в сообщении, но это необязательно. Если название не предоставлено и не читается в логотипе, используются образцы `BRAND NAME` и `Tagline / Descriptor`. Без логотипа навык попросит его прикрепить.

Для правок: «Сохрани логотип и композицию. Сделай палитру спокойнее и обнови фотографии». Ответы следуют языку пользователя; заголовки разделов по умолчанию остаются на английском, как в исходном задании.

## Установка из GitHub

В репозитории уже есть каталог плагинов `.agents/plugins/marketplace.json`. После публикации добавьте адрес репозитория как источник плагинов в поддерживающем эту функцию интерфейсе. Наличие локальных и Git-каталогов зависит от продукта и настроек рабочего пространства.

Для Codex CLI, где доступны команды `codex plugin`, замените `OWNER` на владельца опубликованного репозитория:

```sh
codex plugin marketplace add https://github.com/OWNER/brand-exploration.git
codex plugin add brand-exploration@brand-exploration-marketplace
```

Приватный репозиторий требует настроенного доступа Git к GitHub. Наличие репозитория само по себе не публикует плагин в общем каталоге ChatGPT. Формат `.codex-plugin/plugin.json` поддерживается OpenAI как совместимый формат пакета; сведения о доступных способах распространения приведены в [документации по упаковке плагинов](https://developers.openai.com/plugins/build/plugins).

## Локальная установка

Из корня распакованного или клонированного репозитория:

```sh
codex plugin marketplace add .
codex plugin add brand-exploration@brand-exploration-marketplace
```

После установки откройте новый чат, чтобы он получил навык. Правила вызова навыков описаны в [документации Skills & Plugins](https://learn.chatgpt.com/docs/skills-and-plugins).

## Публикация исходников

Создайте на GitHub пустой репозиторий `brand-exploration` с нужной видимостью. Не добавляйте README при создании: он уже находится в этом пакете.

Если скачан архив, сначала распакуйте его и создайте локальную историю:

```sh
git init -b main
git add .gitignore README.md .agents/plugins/marketplace.json plugins
git commit -m "Add Brand Exploration plugin"
```

Для отправки готового локального репозитория замените `OWNER` на своего пользователя или организацию:

```sh
git remote add origin https://github.com/OWNER/brand-exploration.git
git push -u origin main
```

При работе с подготовленной папкой, в которой уже есть `.git`, повторная инициализация и первый коммит не нужны.

## Ограничения и проверка

Это визуальное исследование для раннего этапа брендинга. Генеративная картинка не гарантирует точное начертание указанных шрифтов, пиксельное совпадение логотипа, размеры или цветовую точность. Навык требует проверить эти места и исправить заметные ошибки. Для финальных носителей используйте исходный логотип и настоящие шрифтовые файлы в редакторе.

Фото в борде могут быть сгенерированы в фотографическом стиле; это не подборка лицензированных стоковых снимков. Навык не выдаёт предполагаемые ценности или отрасль за подтверждённые сведения о компании. Если генерация в текущем чате недоступна, он сообщает об этом и не запускает платный API автоматически.

Проверка упаковки не заменяет проверку изображения на реальном логотипе. Для пробного запуска проверьте: все девять разделов и их количества, узнаваемость знака, читаемость подписей, согласованность палитры и точность текста. Отдельно попробуйте запрос без вложения и правку существующего борда.
